# 32 inch LED television, modelled in code

A complete, parametric 3D model of a 32 inch direct-lit LED LCD television and
its accessories, built with Python and build123d:

- **The television:** enclosure, LCD panel, backlight, steel chassis, six
  circuit boards with 140 placed components, speakers and cables
- **The wall mount:** a 3D-printable French-cleat mount (VESA 100 x 100)
- **Accessories:** stand feet and an infrared remote control
- **Electrical design:** block diagram, power budget, connector pinouts and a
  bill of materials

**Status:** modelled, exported, viewable in the browser, and passing all 122
validation checks. It is a reference design. Nothing has been built, printed or
tested, and the electrical design is at block level with no schematics. Read
the limits in each design document before relying on any of it.

## Setup (once)

Windows PowerShell, from this folder:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

macOS / Linux:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Look at it

```powershell
.\.venv\Scripts\python.exe -m http.server 5173 --bind 127.0.0.1
```

Then open <http://localhost:5173/>. Press Ctrl+C in the terminal to stop it.

- **Show** buttons switch between the whole TV, the back cover off, the boards
  alone, the backlight, the wall mount and the remote.
- **Parts** lists every item in groups; tick or untick a group or a single item.
  This is how you separate the wall mount from the TV, or show the stand feet.
- **Explode** pulls every layer apart.
- **Click any part** for a card saying what it is, what it does and what it
  connects to. Components carry labels (U1, C3, CN2 ...) when you zoom in.
- **Electrical** lists all 49 nets: power rails, mains, control, video, audio
  and data. Pick one to light up every part, cable and copper trace on it.
- It must be served like this; opening `index.html` by double-click will not
  work, because browsers block pages on disk from loading other files.
- three.js (version 0.160.0) loads from the jsDelivr CDN, so the page needs
  internet access the first time.

Ready-made pictures are in `output/renders/`.

## Regenerate everything

After changing `config.py` or `tv/board_data.py`, run these in order:

```powershell
.\.venv\Scripts\python.exe config.py       # are the numbers consistent?
.\.venv\Scripts\python.exe tv_assembly.py  # does the TV build, with no clashes?
.\.venv\Scripts\python.exe electrical.py   # power budget; writes ELECTRICAL.md and the BOM
.\.venv\Scripts\python.exe export.py       # write STEP and STL files
.\.venv\Scripts\python.exe render.py       # write PNG pictures (about a minute)
.\.venv\Scripts\python.exe validate.py     # full pass / fail report (about 2 minutes)
```

Each script prints PASS / FAIL and exits with a non-zero code on failure.
`validate.py` is the one to trust: it repeats every other check and fails if the
exported files no longer match the design.

## Changing the design

| To change | Edit |
|-----------|------|
| Any size: screen, bezel, depth, layer thicknesses, board positions, the mount | `config.py` |
| What is on a circuit board and where | `tv/board_data.py` |
| What a component does and what it connects to | `tv/netlist.py` |
| Power rails, loads and connector pinouts | `electrical.py` |

No other file holds dimensions.

## Outputs

| Folder | Contents |
|--------|----------|
| `output/step/television_complete.step` | Everything in one STEP file. Open this in Fusion 360 |
| `output/step/tv/` | One STEP per television item |
| `output/step/` | Wall-mount parts and `tv_wall_mount.step` |
| `output/stl/` | STL meshes in assembly position, plus `manifest.json` for the viewer |
| `output/stl_print/` | Wall-mount parts laid flat on the bed. **Load these in your slicer.** Print `cable_clip.stl` twice |
| `output/renders/` | `tv_front`, `tv_back`, `tv_inside`, `tv_boards`, `tv_exploded`, `remote`, and five `mount_*` views |
| `output/bom.csv` | Bill of materials |

## Files

| File | Purpose |
|------|---------|
| `config.py` | Every named dimension and rating, plus quick consistency checks |
| `tv/board_data.py` | Component tables for all six circuit boards |
| `tv/netlist.py` | The net list: what each component does and which nets it touches |
| `tv/boards.py` | Turns those tables into 3D boards |
| `tv/panel.py` | LCD cell, films, diffuser, backlight, steel chassis, source boards |
| `tv/enclosure.py` | Front bezel and rear cover |
| `tv/hardware.py` | Speakers, mains inlet, screws, stand feet, all cables |
| `tv/remote.py` | Remote control |
| `tv_assembly.py` | Builds the whole TV; mass, centre of mass and clash check |
| `electrical.py` | Power budget, pinouts; writes ELECTRICAL.md and the BOM |
| `parts/` | The four wall-mount parts |
| `assembly.py` | Wall-mount assembly and its clash check |
| `printing.py` | Print orientation and printability check for the mount |
| `strength.py` | Wall-mount strength hand calculation |
| `export.py` | STEP and STL export |
| `render.py` | PNG renders (a small numpy renderer, no GPU needed) |
| `validate.py` | Pass / fail validation report |
| `index.html` | three.js web viewer |
| `viewer_boards.js` | Draws the circuit boards in detail: components, traces, silkscreen |
| `smoke_test.py` | Confirms the CAD toolchain works on this machine |
